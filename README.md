## 🚀 সেটআপ (মাত্র ২ ধাপ)

### ধাপ ১ — Supabase-এ ডাটাবেস তৈরি করুন (একবারই লাগবে)
1. https://supabase.com/dashboard -এ লগইন করুন (আগের মেস অ্যাপের প্রজেক্টটাই ব্যবহার হবে)
2. বাম মেনু থেকে **SQL Editor** → **New query**
3. এই ফোল্ডারের **`classroom-schema.sql`** ফাইলের পুরো কোড কপি করে পেস্ট করুন
4. **Run** চাপুন ✅ (টেবিল + স্টোরেজ বাকেট তৈরি হয়ে যাবে)

### ধাপ ২ — অ্যাপ চালু করুন
**লোকাল টেস্ট:** `index.html` ডাবল-ক্লিক করে ব্রাউজারে খুলুন — ব্যস, চলবে!

**সবার জন্য অনলাইনে আনতে (ফ্রি):**
1. https://app.netlify.com/drop খুলুন
2. এই `5th-classroom` ফোল্ডারটা ড্র্যাগ করে ছেড়ে দিন
3. একটা লিংক পাবেন (যেমন `https://class5.netlify.app`) — সেটা ছাত্রদের শেয়ার করুন 🎉

## 📱 APK বানাতে চাইলে (ঐচ্ছিক)
আগের মেস অ্যাপের মতোই Capacitor দিয়ে বানানো যায়:
1. `apk-build` ফোল্ডারের কপি বানান
2. `capacitor.config.json`-এ বদলান: `"appId": "com.fahim.class5"`, `"appName": "৫ম ক্লাসরুম"`
3. এই ফোল্ডারের সব ফাইল `www` ফোল্ডারে কপি করুন
4. তারপর আগের মতোই: `npx cap sync` → Android Studio-তে খুলে Build APK
